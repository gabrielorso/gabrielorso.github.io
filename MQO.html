Agora vamos chegar aos mesmos parâmetros realizando o método dos mínimos quadrados ordinários passo a passo.

Mínimos Quadrados Ordinários

O método dos mínimos quadrados ordinários (MQO) é o principal método de estimação dos parâmetros em modelos lineares. Seu objetivo é encontrar os valores dos parâmetros que resultam na menor soma de quadrados dos resíduos.

É importante separar o cálculo dos estimadores de MQO dos pressupostos utilizados para estabelecer suas propriedades estatísticas e realizar inferência. A minimização da soma de quadrados pode ser realizada mesmo sem pressupor normalidade dos erros. No modelo linear clássico, as condições usuais incluem:

  • 1. Média condicional do erro igual a zero: \(E(\epsilon_i \mid X) = 0\);
  • 2. Homocedasticidade: \(\operatorname{Var}(\epsilon_i \mid X) = \sigma^2\);
  • 3. Ausência de correlação entre os erros: \(\operatorname{Cov}(\epsilon_i,\epsilon_j \mid X)=0\), para \(i \neq j\).

Quando se deseja realizar inferência exata em amostras finitas por meio das distribuições \(t\) e \(F\), é comum acrescentar a hipótese de normalidade:

\[ \boldsymbol{\epsilon}\mid X \sim N(\mathbf{0},\sigma^2I). \]

A normalidade dos erros não é necessária para calcular os estimadores de MQO nem para o resultado de Gauss–Markov. Ela é uma hipótese adicional para a inferência exata no modelo linear normal.

A formulação tradicional do modelo linear simples é

\[ y_i = \beta_0 + \beta_1x_i + \epsilon_i. \]

Onde \(\beta_0\) é o intercepto ou constante; \(\beta_1\) é o coeficiente angular associado à variável \(x\); e \(\epsilon_i\) é o erro aleatório da \(i\)-ésima observação, representando a diferença entre o valor observado e o valor esperado pelo modelo. Outra notação encontrada na literatura é \(y = \alpha + \beta x + \epsilon\).

O valor esperado de \(y_i\), condicionado a \(x_i\), é

\[ E(Y_i\mid x_i) = \beta_0 + \beta_1x_i. \]

Como os parâmetros verdadeiros \(\beta_0\) e \(\beta_1\) são desconhecidos, eles são estimados a partir da amostra. Os valores ajustados ou preditos são denotados por

\[ \hat{y}_i = \hat{\beta}_0 + \hat{\beta}_1x_i. \]

O erro populacional é

\[ \epsilon_i = y_i - (\beta_0 + \beta_1x_i), \]

e não é diretamente observável, pois depende dos parâmetros populacionais desconhecidos.

Após o ajuste do modelo, obtém-se o resíduo

\[ e_i = y_i - \hat{y}_i. \]

Portanto, erro e resíduo não são sinônimos: \(\epsilon_i\) pertence ao modelo populacional, enquanto \(e_i\) é calculado após a estimação do modelo.

Como citado anteriormente, o objetivo do MQO é encontrar os parâmetros que resultem na menor soma de quadrados dos resíduos. Se simplesmente somássemos os resíduos, valores positivos e negativos poderiam se compensar. Além disso, em uma regressão com intercepto ajustada por MQO, a soma dos resíduos é exatamente zero:

\[ \sum_{i=1}^{n}e_i = 0. \]

Por isso, a soma simples dos resíduos não mede adequadamente a magnitude dos desvios. Ao elevar cada resíduo ao quadrado, eliminamos o sinal, penalizamos mais fortemente desvios grandes e obtemos uma função diferenciável com solução analítica conveniente.

Essa ainda é uma justificativa intuitiva. Uma fundamentação probabilística adicional surge quando se assume normalidade dos erros: nesse caso, minimizar a soma de quadrados dos resíduos é equivalente a maximizar a função de verossimilhança.

Para qualquer par de valores candidatos \(b_0\) e \(b_1\), podemos escrever

\[ e_i(b_0,b_1) = y_i - b_0 - b_1x_i. \]

Assim, a função a ser minimizada é

\[ S(b_0,b_1) = \sum_{i=1}^{n}e_i(b_0,b_1)^2 = \sum_{i=1}^{n}(y_i-b_0-b_1x_i)^2. \]

Os valores de \(b_0\) e \(b_1\) que minimizam essa função serão chamados de \(\hat{\beta}_0\) e \(\hat{\beta}_1\).

Agora, se atribuirmos valores quaisquer para \(b_0\) e \(b_1\) e calcularmos o somatório, obteremos um valor de \(S\). Conforme os valores dos parâmetros mudam, a Soma de Quadrados dos Resíduos também muda.

# Função que calcula a soma de quadrados dos resíduos
S <- function(x, y, b0, b1) {
  sum((y - b0 - b1 * x)^2)
}

# Para visualizar apenas o efeito de b0 sobre S,
# mantemos b1 fixo.
b1.fixo <- unname(coef(spurr)[2])
b0.centro <- unname(coef(spurr)[1])

# Valores candidatos de b0 ao redor da região do mínimo
b_0 <- seq(
  from = b0.centro - 0.10,
  to   = b0.centro + 0.10,
  length.out = 201
)

# Calcula S para cada valor de b0, mantendo b1 constante
S.est <- vapply(
  b_0,

    S(
      x = dados$d2h,
      y = dados$v,
      b0 = b0,
      b1 = b1.fixo

  FUN.VALUE = numeric(1)
)

df <- data.frame(

Na figura acima, apenas \(b_0\) varia, enquanto \(b_1\) permanece fixo. Dessa forma, o gráfico representa um corte unidimensional da função \(S(b_0,b_1)\). Percebe-se que existe um valor de \(b_0\) para o qual \(S\) é mínimo. Se repetíssemos o procedimento variando apenas \(b_1\), mantendo \(b_0\) fixo, observaríamos o mesmo comportamento quadrático.

Na realidade, \(S\) depende simultaneamente de dois parâmetros. Portanto, no caso da regressão linear simples, podemos imaginar \(S(b_0,b_1)\) como uma superfície. O MQO procura o ponto mais baixo dessa superfície.

Uma maneira de encontrar pontos críticos de uma função diferenciável é igualar suas derivadas a zero. Entretanto, uma derivada igual a zero, isoladamente, pode indicar um ponto de mínimo, máximo ou, em problemas multidimensionais, até um ponto de sela. No caso do MQO, a função \(S\) é quadrática e convexa; portanto, sob as condições usuais de posto da matriz de regressão, o ponto crítico corresponde ao mínimo global.

Para encontrarmos \(\hat{\beta}_0\) e \(\hat{\beta}_1\), derivaremos \(S\) em relação aos parâmetros. Esse procedimento é chamado de derivada parcial, denotada por \(\partial\).

Primeiramente, podemos expandir o quadrado:

\[ S(\beta_0,\beta_1) = \sum_{i=1}^{n} (y_i-\beta_0-\beta_1x_i)^2, \]

\[ S(\beta_0,\beta_1) = \sum_{i=1}^{n} \left( y_i^2 +\beta_0^2 +\beta_1^2x_i^2 -2y_i\beta_0 -2y_i\beta_1x_i +2\beta_0\beta_1x_i \right). \]

Derivada parcial em relação a \(\beta_0\)

As regras de derivação são as mesmas de qualquer outra diferenciação. Como a variável de interesse é \(\beta_0\), os termos que não dependem de \(\beta_0\) são tratados como constantes.

\[ \frac{\partial S}{\partial \beta_0} = \sum_{i=1}^{n} \left( 2\beta_0 -2y_i +2\beta_1x_i \right). \]

No ponto que minimiza \(S\), \(\beta_0=\hat{\beta}_0\) e \(\beta_1=\hat{\beta}_1\). Assim,

\[ \left. \frac{\partial S}{\partial \beta_0} \right|_{\hat{\beta}_0,\hat{\beta}_1} = \sum_{i=1}^{n} \left( 2\hat{\beta}_0 -2y_i +2\hat{\beta}_1x_i \right) = 0. \]

Colocando 2 em evidência,

\[ 2 \sum_{i=1}^{n} \left( \hat{\beta}_0-y_i+\hat{\beta}_1x_i \right) = 0. \]

Dividindo por 2 e multiplicando por \(-1\),

\[ \sum_{i=1}^{n} \left( y_i-\hat{\beta}_0-\hat{\beta}_1x_i \right) = 0. \]

Observe que o termo entre parênteses é exatamente o resíduo \(e_i\). Portanto, uma consequência do MQO em modelos com intercepto é

\[ \sum_{i=1}^{n}e_i=0. \]

Expandindo o somatório,

\[ \sum_{i=1}^{n}y_i - n\hat{\beta}_0 - \hat{\beta}_1\sum_{i=1}^{n}x_i = 0. \]

Dividindo tudo por \(n\),

\[ \frac{\sum_{i=1}^{n}y_i}{n} - \hat{\beta}_0 - \hat{\beta}_1 \frac{\sum_{i=1}^{n}x_i}{n} = 0. \]

Como

\[ \bar{y}=\frac{\sum_{i=1}^{n}y_i}{n} \qquad\text{e}\qquad \bar{x}=\frac{\sum_{i=1}^{n}x_i}{n}, \]

temos

\[ \bar{y} - \hat{\beta}_0 - \hat{\beta}_1\bar{x} = 0, \]

e, portanto,

\[ \boxed{ \hat{\beta}_0 = \bar{y} - \hat{\beta}_1\bar{x} }. \]

Derivada parcial em relação a \(\beta_1\)

A derivada de \(S\) em relação a \(\beta_1\) é

\[ \frac{\partial S}{\partial \beta_1} = \sum_{i=1}^{n} \left( 2\beta_1x_i^2 -2y_ix_i +2\beta_0x_i \right). \]

Colocando \(2x_i\) em evidência,

\[ \frac{\partial S}{\partial \beta_1} = 2 \sum_{i=1}^{n} x_i \left( \beta_1x_i-y_i+\beta_0 \right). \]

No ponto de mínimo,

\[ \left. \frac{\partial S}{\partial \beta_1} \right|_{\hat{\beta}_0,\hat{\beta}_1} = 2 \sum_{i=1}^{n} x_i \left( \hat{\beta}_1x_i-y_i+\hat{\beta}_0 \right) = 0. \]

Dividindo por 2,

\[ \sum_{i=1}^{n} x_i \left( -y_i+\hat{\beta}_0+\hat{\beta}_1x_i \right) = 0. \]

Expandindo,

\[ -\sum_{i=1}^{n}x_iy_i + \hat{\beta}_0\sum_{i=1}^{n}x_i + \hat{\beta}_1\sum_{i=1}^{n}x_i^2 = 0. \]

Portanto,

\[ \hat{\beta}_0\sum_{i=1}^{n}x_i + \hat{\beta}_1\sum_{i=1}^{n}x_i^2 = \sum_{i=1}^{n}x_iy_i. \]

Encontradas as duas equações, ainda precisamos resolvê-las simultaneamente. Uma solução é substituir

\[ \hat{\beta}_0 = \bar{y} - \hat{\beta}_1\bar{x} \]

na segunda equação normal:

\[ (\bar{y}-\hat{\beta}_1\bar{x}) \sum_{i=1}^{n}x_i + \hat{\beta}_1\sum_{i=1}^{n}x_i^2 = \sum_{i=1}^{n}x_iy_i. \]

Como

\[ \bar{x} = \frac{\sum_{i=1}^{n}x_i}{n}, \]

então

\[ \sum_{i=1}^{n}x_i=n\bar{x}. \]

Logo,

\[ (\bar{y}-\hat{\beta}_1\bar{x})n\bar{x} + \hat{\beta}_1\sum_{i=1}^{n}x_i^2 = \sum_{i=1}^{n}x_iy_i, \]

\[ n\bar{x}\bar{y} - \hat{\beta}_1n\bar{x}^2 + \hat{\beta}_1\sum_{i=1}^{n}x_i^2 = \sum_{i=1}^{n}x_iy_i, \]

\[ -\hat{\beta}_1n\bar{x}^2 + \hat{\beta}_1\sum_{i=1}^{n}x_i^2 = \sum_{i=1}^{n}x_iy_i - n\bar{x}\bar{y}, \]

\[ \hat{\beta}_1 \left( \sum_{i=1}^{n}x_i^2-n\bar{x}^2 \right) = \sum_{i=1}^{n}x_iy_i - n\bar{x}\bar{y}. \]

Assim,

\[ \boxed{ \hat{\beta}_1 = \frac{ \displaystyle \sum_{i=1}^{n}x_iy_i - n\bar{x}\bar{y} }{ \displaystyle \sum_{i=1}^{n}x_i^2 - n\bar{x}^2 } } \]

ou, de forma equivalente,

\[ \boxed{ \hat{\beta}_1 = \frac{ \displaystyle \sum_{i=1}^{n}x_iy_i - \frac{ \left(\sum_{i=1}^{n}x_i\right) \left(\sum_{i=1}^{n}y_i\right) }{n} }{ \displaystyle \sum_{i=1}^{n}x_i^2 - \frac{ \left(\sum_{i=1}^{n}x_i\right)^2 }{n} } }. \]

Uma forma ainda bastante comum de escrever o mesmo estimador é

\[ \boxed{ \hat{\beta}_1 = \frac{ \sum_{i=1}^{n} (x_i-\bar{x})(y_i-\bar{y}) }{ \sum_{i=1}^{n} (x_i-\bar{x})^2 } }. \]

Agora podemos calcular os valores de \(\hat{\beta}_0\) e \(\hat{\beta}_1\) diretamente.

O caso mostrado acima foi montado para a regressão linear simples, com os parâmetros \(\hat{\beta}_0\) e \(\hat{\beta}_1\). O sistema de equações normais é

\[ \begin{cases} n\hat{\beta}_0 + \hat{\beta}_1\displaystyle\sum_{i=1}^{n}x_i = \displaystyle\sum_{i=1}^{n}y_i \\[0.5em] \hat{\beta}_0\displaystyle\sum_{i=1}^{n}x_i + \hat{\beta}_1\displaystyle\sum_{i=1}^{n}x_i^2 = \displaystyle\sum_{i=1}^{n}x_iy_i \end{cases} \]

Para uma regressão linear múltipla, com mais de uma variável explicativa, o processo é semelhante, mas o número de equações normais aumenta com o número de parâmetros.

Quando muitas variáveis são adicionadas, é mais conveniente escrever o problema por meio de álgebra matricial.

Considere o modelo

\[ \mathbf{Y} = \mathbf{X}\boldsymbol{\beta} + \boldsymbol{\epsilon}. \]

Adotaremos \(p\) como o número total de parâmetros do modelo, incluindo o intercepto. Assim,

\[ \boldsymbol{\beta} = \begin{bmatrix} \beta_0\\ \beta_1\\ \vdots\\ \beta_{p-1} \end{bmatrix}_{p\times1}, \qquad \mathbf{Y} = \begin{bmatrix} y_1\\ y_2\\ \vdots\\ y_n \end{bmatrix}_{n\times1}, \qquad \boldsymbol{\epsilon} = \begin{bmatrix} \epsilon_1\\ \epsilon_2\\ \vdots\\ \epsilon_n \end{bmatrix}_{n\times1}. \]

A matriz de regressão é

\[ \mathbf{X} = \begin{bmatrix} 1 & x_{11} & \cdots & x_{1,p-1}\\ 1 & x_{21} & \cdots & x_{2,p-1}\\ \vdots & \vdots & \ddots & \vdots\\ 1 & x_{n1} & \cdots & x_{n,p-1} \end{bmatrix}_{n\times p}. \]

Após a estimação,

\[ \hat{\mathbf{Y}} = \mathbf{X}\hat{\boldsymbol{\beta}}, \]

e o vetor de resíduos é

\[ \mathbf{e} = \mathbf{Y} - \hat{\mathbf{Y}} = \mathbf{Y} - \mathbf{X}\hat{\boldsymbol{\beta}}. \]

Assim como anteriormente, queremos minimizar a soma de quadrados dos resíduos. Para um vetor candidato de parâmetros \(\boldsymbol{\beta}\),

\[ S(\boldsymbol{\beta}) = (\mathbf{Y}-\mathbf{X}\boldsymbol{\beta})^\top (\mathbf{Y}-\mathbf{X}\boldsymbol{\beta}). \]

Expandindo,

\[ S(\boldsymbol{\beta}) = \mathbf{Y}^\top\mathbf{Y} - \mathbf{Y}^\top\mathbf{X}\boldsymbol{\beta} - \boldsymbol{\beta}^\top\mathbf{X}^\top\mathbf{Y} + \boldsymbol{\beta}^\top\mathbf{X}^\top\mathbf{X}\boldsymbol{\beta}. \]

Como \(\mathbf{Y}^\top\mathbf{X}\boldsymbol{\beta}\) é um escalar,

\[ \mathbf{Y}^\top\mathbf{X}\boldsymbol{\beta} = \boldsymbol{\beta}^\top\mathbf{X}^\top\mathbf{Y}. \]

Portanto,

\[ S(\boldsymbol{\beta}) = \mathbf{Y}^\top\mathbf{Y} - 2\boldsymbol{\beta}^\top\mathbf{X}^\top\mathbf{Y} + \boldsymbol{\beta}^\top\mathbf{X}^\top\mathbf{X}\boldsymbol{\beta}. \]

O gradiente em relação a \(\boldsymbol{\beta}\) é

\[ \nabla_{\boldsymbol{\beta}}S = -2\mathbf{X}^\top\mathbf{Y} + 2\mathbf{X}^\top\mathbf{X}\boldsymbol{\beta}. \]

No ponto de mínimo, \(\boldsymbol{\beta}=\hat{\boldsymbol{\beta}}\) e o gradiente é igual a zero:

\[ -2\mathbf{X}^\top\mathbf{Y} + 2\mathbf{X}^\top\mathbf{X}\hat{\boldsymbol{\beta}} = 0, \]

\[ \mathbf{X}^\top\mathbf{X}\hat{\boldsymbol{\beta}} = \mathbf{X}^\top\mathbf{Y}. \]

Essas são as equações normais em forma matricial.

Se \(\mathbf{X}\) possui posto completo de colunas, então \(\mathbf{X}^\top\mathbf{X}\) é invertível e

\[ \boxed{ \hat{\boldsymbol{\beta}} = (\mathbf{X}^\top\mathbf{X})^{-1} \mathbf{X}^\top\mathbf{Y} }. \]

Além disso, a matriz Hessiana da função \(S\) é

\[ \mathbf{H} = 2\mathbf{X}^\top\mathbf{X}. \]

Quando \(\mathbf{X}\) possui posto completo, \(\mathbf{X}^\top\mathbf{X}\) é definida positiva. Portanto, o ponto crítico encontrado acima é o único mínimo global da soma de quadrados.
